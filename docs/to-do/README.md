# Next actions and lessons

Updated 1 November 2026 (Asia/Bangkok). Completed work and measured status are in
[current progress](../current-progress/README.md). This directory contains future
work, open dependencies and guidance for the next phase.

Start with the [Phase 5 closeout and Phase 6 handoff](phase-6.md). It covers:

1. Close the evidence gap: additional permitted tick periods, effective-dated
   membership and independently evaluated after-cost strategy performance.
2. Resolve stock selection, exposure and trading-horizon conflicts without
   manufacturing round trips or calling historical payoff a future forecast.
3. Retain or reject each added rule using matched comparisons and actual
   execution sensitivities, preserving all failed experiments.
4. Freeze an explicitly named candidate/fallback and rehearse same-day state
   recovery, partial/rejected fills, missing data and runtime.
5. Confirm organizer identity, submission repository/procedure, acceptance,
   schedule and operational monitoring before production use.

The user's Phase 5 request supersedes the earlier ten-name cap and proposed
15-name restriction. Continue with all **available** supplied constituents,
currently 48; obtain valid membership and data before claiming all 50. Equal
and quality variants use per-stock eligibility rather than compulsory trading
in every constituent.

Carry these lessons forward: completed-lot payoff can hide open losses;
fragmented IOC fills inflate FIFO counts relative to position episodes; narrow
signals may be unable to satisfy average exposure; cash-based outperformance
against a falling index is not sufficient for Best Alpha; the pre-start
five-session proxy did not establish a positive stock edge. Reused September
data are development evidence, not a holdout.

Use the [strategy explanations](../phase-5-strategies.md),
[Phase 5 report](../result-data-visualisation/phase-5/phase-5-results.md),
[research declaration](../phase-5-research-spec.md), and

Keep the original baseline as the engineering fallback until a replacement
passes the declared evidence gates. Phase 6 compatibility work can proceed
